Core Pillars of Quarkus 4

Quarkus 4 is built around key enterprise capabilities designed to scale modern applications.

Next-Gen Foundations

Quarkus 4 updates the baseline technologies powering high-performance Java runtimes.

  • Java 21 baseline: Makes virtual threads central to execution and concurrency models across the framework.
  • CDI 5.0 specification: Integrates new dependency injection annotations including @Reserve and @Eager.
  • Updated core networking: Built upon Netty 4.2 and Vert.x 5.x for improved throughput.
  • JPMS modularity support: Native support for building modular Java applications.
  • Graceful shutdown sequences: Redesigned lifecycle architecture supporting ordered startup and shutdown phases.

Core Framework Enhancements

  • Signal Event Bus: An in-process asynchronous communication mechanism featuring typesafe delivery semantics, built-in observability, and integrated security.
  • Observation API: Unified metric and trace generation via @Observed or programmatic APIs, fully compatible with Micrometer and OpenTelemetry.
  • Ahead-of-Time (AOT) snapshotting: Enhanced integration with Project Leyden and CRaC/InstantOn technologies.
  • Extended Spring compatibility: Seamless migration paths supporting Spring Framework 7 APIs, Spring Data 4, and @SpringBootTest.
  • Roq static site engine: The quarkus.io platform itself transitions to Roq, a Quarkus-native static site generator.

Modern Networking Stack

Quarkus 4 advances distributed communications with modern networking standards.

  • QUIC and HTTP/3 support: Native foundation for modern distributed systems supporting HTTP/3, MQTT over QUIC, and WebTransport.
  • Automated certificate handling: Zero-configuration TLS/SSL certificate generation during development and testing modes.
  • Native OS transports: Maximizes concurrency using native Linux epoll or io_uring transports inside JVM and native executables.
  • gRPC transcoding: Direct invocation of gRPC services from web browsers without requiring external reverse proxies.
  • Jakarta REST 4: Updated API standards supporting JSON Merge Patch and modern multipart data handling.

Advanced Data & Messaging Capabilities

  • Dedicated JMS extension: Comprehensive JMS integration compatible with Spring JMS, pooled connections, and IronJacamar.
  • Reactive Messaging TableView API: Enables stateful stream processing, materialized views, exactly-once delivery semantics (@ExactlyOnce), and Kafka transaction management.
  • Panache 2: Supports blocking and reactive pipelines, stateful or stateless sessions, compile-time query validation, and improved pagination.
  • Persistence upgrade: Native integration with Hibernate 8, Jakarta Persistence 4.0, and Jakarta Data 1.1.

Native Intelligence & Agentic AI Systems

Quarkus 4 natively integrates contextual AI protocols and agentic developer tooling.

  • MCP Server 2.0: Full implementation of the Model Context Protocol (MCP 2026-07-28 specification) with a clean annotation-driven programming model.
  • Non-blocking LangChain4j: Asynchronous AI APIs optimized for reactive execution without thread blocking.
  • Chat scopes and conversation management: Built-in lifecycle scopes for short-term memory, conversation passivation, and state resumability.
  • Agent MCP developer experience: Developer Mode enhancements tailored for AI coding agents, exposing live application state and documentation to minimize token costs and maximize code generation accuracy.
