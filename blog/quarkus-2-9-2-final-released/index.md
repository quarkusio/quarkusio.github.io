# Quarkus 2.9.2.Final released - Maintenance release

Today, we released Quarkus 2.9.2.Final, our second maintenance release for 2.9. It comes with a bunch of fixes and documentation improvements.

It is a safe upgrade for anyone already using 2.9 and is highly recommended.

If you are not using 2.9 already, please refer to the [2.9 migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-2.9).

## Full changelog

You can get [the full changelog of 2.9.2.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/2.9.2.Final).
