# Quarkus 2.11.3.Final released - Fix for CVE-2022-2466 and other bugfixes

2.11.3.Final is our third maintenance release for the 2.11 release train.

It is a safe upgrade for anyone using 2.11.

Among other issues, it fixes CVE-2022-2466 that was affected our `quarkus-smallrye-graphql` extension.

## Migration Guide

If you are not already using 2.11, please refer to [our migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-2.11).

## Full changelog

You can get [the full changelog of 2.11.3.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/2.11.3.Final).
