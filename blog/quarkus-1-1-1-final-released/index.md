# Quarkus 1.1.1.Final released - Bugfixes only

We just released 1.1.1.Final to push a series of bugfixes and documentation improvements early. We are still working hard on preparing our next big version, which will be 1.2, released in late January.

This is a safe upgrade for everyone using 1.1.0.Final.

## What's new?

### Bugfixes and documentation improvements

We introduced some big changes in our Gradle support for 1.1 and we got some interesting feedback. 1.1.1.Final fixes all the issues reported so far.

We also polished a few things in our Kotlin support.

Apart from that, we fixed minor issues here and there and polished the documentation.

### Full changelog

You can get [the full changelog of 1.1.1.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/1.1.1.Final).
