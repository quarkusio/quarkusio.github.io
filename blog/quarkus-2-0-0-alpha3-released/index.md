# Quarkus 2.0.0.Alpha3 released - GraalVM 21.1, SmallRye GraphQL Client...

We just released our third Alpha for Quarkus 2.0 which contains several enhancements and new features:

- [#17014](https://github.com/quarkusio/quarkus/pull/17014) - Update to GraalVM 21.1
- [#17350](https://github.com/quarkusio/quarkus/pull/17350) - SmallRye GraphQL Client extension + 1.2.1 upgrade
- [#16857](https://github.com/quarkusio/quarkus/pull/16857) - Add Amazon SSM extension
- [#16963](https://github.com/quarkusio/quarkus/pull/16963) - Add `quarkus:test` goal
- [#17232](https://github.com/quarkusio/quarkus/pull/17232) - Introduce coroutine support in Reactive Messaging
- [#17056](https://github.com/quarkusio/quarkus/pull/17056) - Add support for coroutines to the rest client
- [#16951](https://github.com/quarkusio/quarkus/pull/16951) - Add support for hibernate.metadata_builder_contributor
