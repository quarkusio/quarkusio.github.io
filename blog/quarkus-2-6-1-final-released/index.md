# Quarkus 2.6.1.Final released - Maintenance release

2021 has been a tremendous year for Quarkus and today we officially close our 2021 release season with the last maintenance release of the year: 2.6.1.Final is available on Maven Central and ready for consumption!

It is a safe upgrade for anyone already using 2.6 and contains dozens of small bugfixes, tweaks and documentation improvements.

Thank you all for taking the time to report issues, build reproducers... it is immensely helpful and instrumental in making Quarkus better every day.

Have a nice holiday break if you take one, and happy coding/experimenting if you don't, and see you all next year.

## Full changelog

If you are not using 2.6 already, please refer to the [2.6 migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-2.6).

You can get [the full changelog of 2.6.1.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/2.6.1.Final).
