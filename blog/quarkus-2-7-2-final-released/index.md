# Quarkus 2.7.2.Final released - Maintenance release

It is our pleasure to announce the release of Quarkus 2.7.2.Final, our second maintenance release for our 2.7 release train.

Some bugfixes are a bit more involved than what we usually include in maintenance releases, so if you encounter any issue upgrading, please report them with as many details as you can (and preferably with a reproducer) in [our tracker](https://github.com/quarkusio/quarkus/issues).

It should be a safe upgrade for anyone already using 2.7 though.

If you are not using 2.7 already, please refer to the [2.7 migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-2.7).

## What's new

### Kogito and OptaPlanner upgrades

Kogito and OptaPlanner have been upgraded respectively to 1.17.0.Final and 8.17.0.Final.
