# Quarkus 1.12.1.Final released - Bugfixes

1.12.1.Final is a maintenance release fixing bugs and improving the documentation.

1.12.1.Final is a safe upgrade for everyone using Quarkus 1.12.

If you are not using 1.12 already, please refer to the [1.12 migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-1.12).

## What's new?

[Path resolution](/blog/path-resolution-in-quarkus/) for configurable endpoints changed in this release.

You can get [the full changelog of 1.12.1.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/1.12.1.Final).
