# Quarkus 3.27.2 released - LTS maintenance release

Today, we released Quarkus 3.27.2, our next maintenance release for the 3.27 LTS stream.

This release contains bugfixes, documentation updates and fixes the following CVEs:

- [CVE-2025-66560](https://nvd.nist.gov/vuln/detail/CVE-2025-66560)
- [CVE-2025-59432](https://nvd.nist.gov/vuln/detail/CVE-2025-59432)
- [CVE-2025-67735](https://nvd.nist.gov/vuln/detail/CVE-2025-67735)
- [CVE-2025-14969](https://nvd.nist.gov/vuln/detail/CVE-2025-14969)

It should be a safe upgrade for anyone already using 3.27.

## Update

To update to Quarkus 3.27, we recommend updating to the latest version of the Quarkus CLI and run:

```bash
quarkus update --stream=3.27
```

Note that `quarkus update` can update your applications from any version of Quarkus (including 2.x) to Quarkus 3.27.
