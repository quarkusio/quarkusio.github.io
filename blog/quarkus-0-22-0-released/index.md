# Quarkus 0.22.0 released

We just released Quarkus 0.22.0 including an improved Spring API support.

We also officially launch [code.quarkus.io](https://code.quarkus.io/): it has never been easier to create a Quarkus application.

## What's new?

### Improved Spring API support

Quarkus has had [a Quarkus Extension for Spring Dependency Injection API](https://quarkus.io/guides/spring-di) since its initial release. The plan has always been to extend Spring API support and executing on that plan, this release brings the addition of [the Quarkus Extension for Spring Web API](https://quarkus.io/guides/spring-web) and [the Quarkus Extension for Spring Data JPA API](https://quarkus.io/guides/spring-data-jpa).

Spring developers can now feel at home with Quarkus while benefiting from features like out-of-the-box support for live coding and native compilation.

### code.quarkus.io

It has been in the works for a while and we are proud to officially launch [code.quarkus.io](https://code.quarkus.io/), a user-friendly web interface to create your Quarkus applications. It also constitutes a great tool to explore the full breadth of our extension ecosystem.

### New extensions

The extension ecosystem is growing very nicely. We are working on a model to streamline extension publications. We call this effort the Quarkus platform. In the mean time we have seen community members wanting to collaborate on extensions, we have created a [new issue template](https://github.com/quarkusio/quarkus/issues/new?assignees=&labels=extension-proposal&template=extension_proposal.md&title=) and [GitHub tag](https://github.com/quarkusio/quarkus/labels/extension-proposal) to capture these.

### Full changelog

We also fixed a few bugs and usability issues: get [the full changelog of 0.22.0 on GitHub](https://github.com/quarkusio/quarkus/releases/tag/0.22.0).
