# Quarkus 2.15.3.Final released - Maintenance release

Today, we released Quarkus 2.15.3.Final, our third maintenance release for Quarkus 2.15. As usual it comes with bugfixes and documentation improvements.

It is a recommended upgrade for anyone already using 2.15.

If you are not already using 2.15, please refer to [our migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-2.15).

## Full changelog

You can get [the full changelog of 2.15.3.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/2.15.3.Final).
