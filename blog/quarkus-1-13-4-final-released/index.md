# Quarkus 1.13.4.Final released - Maintenance release

We just released 1.13.4.Final, a new maintenance release for the 1.13 release train.

1.13.4.Final is a safe upgrade for everyone using Quarkus 1.13.

If you are not using 1.13 already, please refer to the [1.13 migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-1.13).
