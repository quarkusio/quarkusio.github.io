# Quarkus 3.6.5 released - Maintenance release

Today, we released Quarkus 3.6.5, our fifth maintenance release for the 3.6 release train.

This release contains bugfixes and documentation improvements.

It should be a safe upgrade for anyone already using 3.6.

## Update

To update to Quarkus 3.6.5, we recommend updating to the latest version of the Quarkus CLI and run:

```bash
quarkus update
```

To migrate from 3.5, please refer to [our migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.6).

If you are not already using 3.x, please refer to the [3.0 announcement](https://quarkus.io/blog/quarkus-3-0-final-released/) for all the details. You can also refer to [this blog post](https://quarkus.io/blog/quarkus-3-upgrade/) for additional details. Once you upgraded to 3.0, also have a look at the [3.1](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.1), [3.2](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.2), [3.3](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.2), [3.4](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.4), and [3.5](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.5) migration guides.
