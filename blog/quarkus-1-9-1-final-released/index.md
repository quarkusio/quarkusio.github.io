# Quarkus 1.9.1.Final released - Bugfixes

Thanks to all your feedback, here comes 1.9.1.Final with bugfixes and documentation improvements.

It is a safe upgrade for everyone using Quarkus 1.9.

If you are not using 1.9 already, please refer to the [1.9 migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-1.9).

## What's new?

This release is a maintenance release that fixes various bugs found in 1.9.0.Final and provides some documentation updates.

You can get [the full changelog of 1.9.1.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/1.9.1.Final).

## Come Join Us

We value your feedback a lot so please report bugs, ask for improvements... Let's build something great together!
