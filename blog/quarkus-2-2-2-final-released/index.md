# Quarkus 2.2.2.Final released - Maintenance release

Today, we released Quarkus 2.2.2.Final, a maintenance release for our 2.2 release train containing bugfixes and documentation improvements.

It is a safe upgrade for anyone already using 2.2.

If you are not using 2.2 already, please refer to the [2.2 migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-2.2).

## Full changelog

You can get [the full changelog of 2.2.2.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/2.2.2.Final).
