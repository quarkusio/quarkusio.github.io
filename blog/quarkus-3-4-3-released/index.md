# Quarkus 3.4.3 released - Maintenance release

Today, we released Quarkus 3.4.3, our second maintenance release for our 3.4 release train (we skipped 3.4.0).

It upgrades Netty to 4.1.100.Final, fixing CVE-2023-44487. It also includes a bunch of bugfixes, together with documentation improvements.

More releases are planned in the following days/weeks to address the issue in other maintained branches.

## Update

To update to Quarkus 3.4.3, we recommend updating to the latest version of the Quarkus CLI and run:

```bash
quarkus update
```

To migrate from 3.3, please refer to [our migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.4).

If you are not already using 3.x, please refer to the [3.0 announcement](https://quarkus.io/blog/quarkus-3-0-final-released/) for all the details. You can also refer to [this blog post](https://quarkus.io/blog/quarkus-3-upgrade/) for additional details. Once you upgraded to 3.0, also have a look at the [3.1](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.1), [3.2](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.2), and [3.3](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.3) migration guides.
