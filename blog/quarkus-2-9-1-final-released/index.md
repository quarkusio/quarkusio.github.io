# Quarkus 2.9.1.Final released - Maintenance release

It is my pleasure to announce the availability of Quarkus 2.9.1.Final, the first maintenance release of our 2.9 release.

It is a safe upgrade for anyone already using 2.9.

If you are not using 2.9 already, please refer to the [2.9 migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-2.9).

## Full changelog

You can get [the full changelog of 2.9.1.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/2.9.1.Final).
