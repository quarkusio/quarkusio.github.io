# Quarkus 1.10.5.Final released - Bugfixes

1.10.5.Final is a maintenance release.

It is a safe upgrade for everyone using Quarkus 1.10.

If you are not using 1.10 already, please refer to the [1.10 migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-1.10).

## What's new?

This release is a maintenance release.

It fixes some important issues in Quarkus, most notably in the Hibernate ORM extension which got Hibernate ORM upgraded to 5.4.26.Final.

You can get [the full changelog of 1.10.4.Final](https://github.com/quarkusio/quarkus/releases/tag/1.10.4.Final) and the [full changelog for 1.10.5.Final](https://github.com/quarkusio/quarkus/releases/tag/1.10.5.Final) on GitHub.
