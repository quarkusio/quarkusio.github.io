# Quarkus Newsletter #74 - November

See how an agentic GitHub pull request reviewer, built with Quarkus LangChain4j, combines a decision router, debates, voting, reflection loops and a human in the loop, with the right model for each step and a cost cap by reading "Debates, voting, and reflection loops: composing an agentic PR reviewer that costs less than a dollar" by Mario Fusco. Fouad Almalki introduces "Quarkus Almanac". The Quarkus Almanac shows what changed between two Quarkus releases: configuration, dependencies, extensions, classes, and their API. Read "Extending Your Quarkus Application with Apache Camel" by Gaelle Fournier to get a practical guide showing how to extend an existing Quarkus REST app with Camel for Kafka events, HTTP service calls with retries, and file ingestion. Markus Eisele demonstrates a few smaller Quarkus features to check before you write more code around your application in "Quarkus Already Does That: 7 More Features Worth Knowing". Learn how Trax uses Quarkus to stream Oracle change data through Debezium and Kafka Streams and push it live to React and Swift iOS clients over WebSockets in "How Trax keeps aircraft maintenance real-time with Quarkus" by Emil Lefkof.

You will also see the latest Quarkus Insights episodes, top social posts and upcoming Quarkus attended events.
