# Quarkus 2.16.9.Final released - Maintenance release

As mentioned in previous blog posts, we encourage all our users to upgrade to Quarkus 3 (it is an easy task with `quarkus update`). However we understand the migration can require some time so we will continue to maintain 2.16.x for a while. Today, we released Quarkus 2.16.9.Final, the ninth maintenance release of our 2.16 release train.

As usual, it contains bugfixes and documentation improvements, most notably the upgrade to gRPC 1.53.0, which fixes a CVE.

It should be a safe upgrade for anyone already using 2.16.

If you are not already using 2.16, please refer to [our migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-2.16).
