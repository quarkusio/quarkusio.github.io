# Quarkus 2.15.2.Final released - Maintenance release

The Quarkus team wishes you a happy new year, and with the new year comes a new Quarkus release, 2.15.2.Final.

This version contains bugfixes and documentation improvements for our 2.15 release train. It is a recommended upgrade for anyone already using 2.15.

If you are not already using 2.15, please refer to [our migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-2.15).

## Full changelog

You can get [the full changelog of 2.15.2.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/2.15.2.Final).
