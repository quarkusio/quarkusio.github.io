# Quarkus 1.11.2.Final released - Bugfixes

1.11.2.Final is a maintenance release fixing bugs and improving the documentation.

It is a safe upgrade for everyone using Quarkus 1.11.

If you are not using 1.11 already, please refer to the [1.11 migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-1.11).

## What's new?

### Hibernate ORM

We upgraded to Hibernate ORM 5.4.27.SP1 which fixes an important issue, potentially causing data losses.

Thus the upgrade is highly recommended.

You can get [the full changelog of 1.11.2.Final on GitHub](https://github.com/quarkusio/quarkus/releases/tag/1.11.2.Final).
