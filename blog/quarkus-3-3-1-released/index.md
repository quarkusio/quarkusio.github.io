# Quarkus 3.3.1 released - Maintenance release

We released Quarkus 3.3.1, our first maintenance release for our 3.3 release train.

It includes a bunch of bugfixes, together with documentation improvements.

We are aware of a [startup performance/memory regression introduced in 3.3](https://github.com/quarkusio/quarkus/issues/35406) and are working hard on fixing it. This issue **is** not solved in 3.3.1 but should be solved in the upcoming 3.3.2 that will be released next week.

## Update

To update to Quarkus 3.3.1, we recommend updating to the latest version of the Quarkus CLI and run:

```bash
quarkus update
```

To migrate from 3.2, please refer to [our migration guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.3).

If you are not already using 3.x, please refer to the [3.0 announcement](https://quarkus.io/blog/quarkus-3-0-final-released/) for all the details. You can also refer to [this blog post](https://quarkus.io/blog/quarkus-3-upgrade/) for additional details. Once you upgraded to 3.0, also have a look at the [3.1](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.1) and [3.2](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.2) migration guides.
