[.description]
--
Fully qualified names of additional classes that are trusted for Avro deserialization.

Since Avro 1.12.2, classes are validated against a global security validator before they are deserialized. Classes generated by Avro (annotated with `@org.apache.avro.specific.AvroGenerated`) are always trusted and do not need to be listed here. Use this property to trust additional, non-generated classes.

[.description]
--
Package names whose classes are trusted for Avro deserialization.

Since Avro 1.12.2, classes are validated against a global security validator before they are deserialized. Matching respects package boundaries: a value of `org.acme` trusts `org.acme.Foo` and classes in any sub-package such as `org.acme.sub.Bar`, but does not trust `org.acme2.Foo`.

Classes generated by Avro (annotated with `@org.apache.avro.specific.AvroGenerated`) are always trusted and do not need to be listed here.
