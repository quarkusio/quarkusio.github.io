[.description]
--
The name of the default realm of the Elytron security domain, which is the realm that authenticates users.

This property is only used when multiple realms are enabled, for example, the properties file realm and the JDBC realm. Its value must be the realm name of one of the enabled realms. When exactly one realm is enabled, that realm is always the default realm.
