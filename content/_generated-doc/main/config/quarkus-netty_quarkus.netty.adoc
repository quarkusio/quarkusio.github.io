_This property is deprecated since `4.0`: This property has no effect anymore._

Ignored. Since Netty 4.2, the default allocator is `io.netty.buffer.AdaptiveByteBufAllocator`, which has its own pooling strategy and ignores `maxOrder`; this property is no longer honored, even when `io.netty.buffer.PooledByteBufAllocator` is selected explicitly.

This property is retained only for compatibility, so that setting it does not fail the build. It can be removed from configuration.
