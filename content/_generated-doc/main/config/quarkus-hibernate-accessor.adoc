[.description]
--
The accessor strategy to use.

`generated`::
use generated bytecode accessors, throw on unrecognized members.
`generated-with-fallback` (default)::
use generated bytecode accessors, fall back to reflection for unrecognized members.
`reflection`::
use pure reflection-based accessors, no bytecode generation.
