[.description]
--
Controls whether the embedded SBOM is served GZIP-compressed through the _endpoint_. This option does not affect how the SBOM is stored in the application: the embedded SBOM resource is always stored uncompressed.

 * if set to `true`, the endpoint always serves the SBOM compressed with `Content-Encoding: gzip`;
 * if set to `false`, the endpoint always serves the SBOM uncompressed;
 * if not set, the endpoint negotiates the encoding based on the request's `Accept-Encoding` header, serving the SBOM compressed only when the client accepts `gzip`.


ifdef::add-copy-button-to-env-var[]
Environment variable: env_var_with_copy_button:+++QUARKUS_CYCLONEDX_EMBEDDED_COMPRESS+++[]
endif::add-copy-button-to-env-var[]
ifndef::add-copy-button-to-env-var[]
Environment variable: `+++QUARKUS_CYCLONEDX_EMBEDDED_COMPRESS+++`
