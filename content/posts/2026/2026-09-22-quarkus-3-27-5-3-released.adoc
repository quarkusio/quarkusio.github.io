Today, we released Quarkus 3.27.5.3, an emergency release for the 3.27 LTS stream.

This release fixes the following CVEs:

- https://nvd.nist.gov/vuln/detail/CVE-2026-77874[CVE-2026-77874] - Hibernate ORM: SQL Injection via unescaped JSON path segment allows data exfiltration and authorization bypass
- https://nvd.nist.gov/vuln/detail/CVE-2026-19611[CVE-2026-19611] - WildFly Elytron: Password keyspace reduction via NFKC fullwidth folding
- https://nvd.nist.gov/vuln/detail/CVE-2026-81829[CVE-2026-81829] - SmallRye JWT: Unauthenticated same-origin SSRF via unsanitized JWT kid header in AwsAlbKeyResolver
- https://nvd.nist.gov/vuln/detail/CVE-2026-87742[CVE-2026-87742] - Quarkus WebSockets Next: Denial of Service (OOM) via unbounded message buffering
- https://nvd.nist.gov/vuln/detail/CVE-2026-87743[CVE-2026-87743] - Quarkus Vert.x HTTP: Authorization bypass via path normalization discrepancy in Quarkus HTTP security
- https://nvd.nist.gov/vuln/detail/CVE-2026-87825[CVE-2026-87825] - zstd-jni: Data corruption or denial of service via use-after-free vulnerability
- https://nvd.nist.gov/vuln/detail/CVE-2026-87877[CVE-2026-87877] - zstd-jni: Use-after-free vulnerability allows memory corruption and denial of service
- https://nvd.nist.gov/vuln/detail/CVE-2026-87795[CVE-2026-87795] - zstd-jni: Out-of-bounds read in ZstdDictCompress constructor leads to denial of service
- https://nvd.nist.gov/vuln/detail/CVE-2026-87824[CVE-2026-87824] - zstd-jni: Denial of Service via out-of-bounds read in Zstd.trainFromBufferDirect
- https://nvd.nist.gov/vuln/detail/CVE-2026-89046[CVE-2026-89046] - zstd-jni: Information disclosure or denial of service via out-of-bounds read
- https://nvd.nist.gov/vuln/detail/CVE-2026-87823[CVE-2026-87823] - zstd-jni: Denial of Service or information disclosure via out-of-bounds read
- https://nvd.nist.gov/vuln/detail/CVE-2026-90560[CVE-2026-90560] - zstd-jni: Denial of Service via out-of-bounds read in ZstdDictDecompress
- https://nvd.nist.gov/vuln/detail/CVE-2026-90852[CVE-2026-90852] - zstd-jni: Remote use-after-free vulnerability in dictionary sharing

- https://nvd.nist.gov/vuln/detail/CVE-2026-94449[CVE-2026-94449] - Quarkus SmallRye Fault Tolerance: Memory leak in @ApplyGuard leads to Denial of Service
- https://nvd.nist.gov/vuln/detail/CVE-2026-93491[CVE-2026-93491] - Netty: Denial of Service via unbounded HttpServerCodec HTTP/1.1 pipeline queue
- https://nvd.nist.gov/vuln/detail/CVE-2026-93558[CVE-2026-93558] - Netty: Unbounded per-connection queue growth in WebSocketServerExtensionHandler leads to Denial of Service
- https://nvd.nist.gov/vuln/detail/CVE-2026-93564[CVE-2026-93564] - Netty: HAProxy PROXY-v2 nested-TLV grandchild ByteBuf reference-count leak
- https://nvd.nist.gov/vuln/detail/CVE-2026-93565[CVE-2026-93565] - Netty: RtspDecoder method-token smuggling via trailing control byte

- https://nvd.nist.gov/vuln/detail/CVE-2026-93568[CVE-2026-93568] - Netty: HTTP/2 and HTTP/3 Extended CONNECT requests are downgraded as regular CONNECT requests

- https://nvd.nist.gov/vuln/detail/CVE-2026-93566[CVE-2026-93566] - Netty: HTTP request smuggling due to control characters in the chunk-size line

It also fixes a native image regression in the RabbitMQ extension.

It should be a safe upgrade for anyone already using 3.27.

== Update

To update to Quarkus 3.27, we recommend updating to the latest version of the Quarkus CLI and run:

[source,bash]
----
quarkus update --stream=3.27
----

Note that `quarkus update` can update your applications from any version of Quarkus (including 2.x) to Quarkus 3.27.
