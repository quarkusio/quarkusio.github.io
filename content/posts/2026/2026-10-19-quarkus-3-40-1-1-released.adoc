Today, we released Quarkus 3.40.1.1, an emergency release for the 3.40 LTS stream.

This release fixes the following CVEs:

- https://nvd.nist.gov/vuln/detail/CVE-2026-93879[CVE-2026-93879]
- https://nvd.nist.gov/vuln/detail/CVE-2026-94451[CVE-2026-94451]
- https://nvd.nist.gov/vuln/detail/CVE-2026-87744[CVE-2026-87744]
- Everything resolved by snappy-java 1.1.10.11
- Everything resolved by lz4-java 1.11.4
- Everything resolved by https://netty.io/news/2026/10/06/4-1-139-Final.html[Netty 4.1.139.Final] (note that, at the time of publishing this announcement, the corresponding CVEs have not been published yet)
- Everything resolved by Vert.x 4.5.35

It should be a safe upgrade for anyone already using 3.40.

== Update

To update to Quarkus 3.40, we recommend updating to the latest version of the Quarkus CLI and run:

[source,bash]
----
quarkus update --stream=3.40
----

Note that `quarkus update` can update your applications from any version of Quarkus (including 2.x) to Quarkus 3.40.
