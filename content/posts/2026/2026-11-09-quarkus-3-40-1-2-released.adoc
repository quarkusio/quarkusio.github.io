Today, we released Quarkus 3.40.1.2, an emergency release for the 3.40 LTS stream.

This release fixes the following CVEs:

- https://nvd.nist.gov/vuln/detail/CVE-2026-107912[CVE-2026-107912] - Quarkus Vert.x HTTP: Authorization bypass in the management interface due to incorrect combination of the management root path with permission rules
- https://nvd.nist.gov/vuln/detail/CVE-2026-110879[CVE-2026-110879] - Jackson Databind: PolymorphicTypeValidator bypass via generic type parameters and array element types of type ids (incomplete fix for CVE-2026-54512)
- https://nvd.nist.gov/vuln/detail/CVE-2026-111497[CVE-2026-111497] - Brotli (via Brotli4J): Heap out-of-bounds write in the Brotli decoder leading to remote code execution
- Everything else resolved by https://github.com/FasterXML/jackson/wiki/Jackson-Release-2.21.8[Jackson 2.21.8] (CVEs in the Avro, CBOR, Protobuf and Smile dataformat modules, which are not part of Quarkus itself but are managed by the Quarkus BOM)

It should be a safe upgrade for anyone already using 3.40.

== Update

To update to Quarkus 3.40, we recommend updating to the latest version of the Quarkus CLI and run:

[source,bash]
----
quarkus update --stream=3.40
----

Note that `quarkus update` can update your applications from any version of Quarkus (including 2.x) to Quarkus 3.40.
