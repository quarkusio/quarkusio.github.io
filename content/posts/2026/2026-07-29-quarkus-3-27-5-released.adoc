Today, we released Quarkus 3.27.5, our next maintenance release for the 3.27 LTS stream.

This release contains bugfixes, documentation updates, and security fixes.

It should be a safe upgrade for anyone already using 3.27.

== Security fixes

This release fixes the following CVEs:

=== Quarkus and direct dependencies

- https://nvd.nist.gov/vuln/detail/CVE-2026-15075[CVE-2026-15075] - Eclipse Vert.x: `DefaultRedirectHandler` cross-origin header propagation
- https://nvd.nist.gov/vuln/detail/CVE-2026-15076[CVE-2026-15076] - Eclipse Vert.x: `WebClientSession` cross-domain cookie injection
- https://nvd.nist.gov/vuln/detail/CVE-2026-53712[CVE-2026-53712] - OnGres SCRAM client: Authentication downgrade
- https://nvd.nist.gov/vuln/detail/CVE-2026-59888[CVE-2026-59888] - Jackson-databind: `@JsonIgnore` bypass with `PropertyNamingStrategy` on Java Records
- https://nvd.nist.gov/vuln/detail/CVE-2026-59889[CVE-2026-59889] - Jackson-databind: `@JsonView` bypass for `@JsonUnwrapped` properties during deserialization
- https://nvd.nist.gov/vuln/detail/CVE-2026-8484[CVE-2026-8484] - Jansi: Heap-based buffer overflow in JNI ioctl() wrapper
- https://nvd.nist.gov/vuln/detail/CVE-2026-55405[CVE-2026-55405] - LangChain4j: SQL injection in embedding store metadata filter

=== Netty

This release upgrades Netty to 4.1.136.Final, which fixes numerous security vulnerabilities including:

- https://nvd.nist.gov/vuln/detail/CVE-2026-55833[CVE-2026-55833] - Zip bomb vulnerability in `netty-codec-http`
- https://nvd.nist.gov/vuln/detail/CVE-2026-59921[CVE-2026-59921] - Improper CR/LF neutralization in `netty-codec-http` (multipart)
- https://nvd.nist.gov/vuln/detail/CVE-2026-59919[CVE-2026-59919] - Improper CR/LF neutralization in `netty-codec-haproxy`
- https://nvd.nist.gov/vuln/detail/CVE-2026-55851[CVE-2026-55851] - Memory exhaustion in `netty-codec-haproxy`
- https://nvd.nist.gov/vuln/detail/CVE-2026-56745[CVE-2026-56745] - Memory exhaustion in `netty-codec-http`
- https://nvd.nist.gov/vuln/detail/CVE-2026-59899[CVE-2026-59899] - Memory exhaustion in `netty-codec-http`
- https://nvd.nist.gov/vuln/detail/CVE-2026-55831[CVE-2026-55831] - Resource exhaustion/DoS in `netty-codec-http`
- https://nvd.nist.gov/vuln/detail/CVE-2026-56819[CVE-2026-56819] - Memory leak in `netty-codec-http2`
- https://nvd.nist.gov/vuln/detail/CVE-2026-59900[CVE-2026-59900] - Improper header neutralization in `netty-codec-http2`
- https://nvd.nist.gov/vuln/detail/CVE-2026-59898[CVE-2026-59898] - Protocol version confusion in `netty-codec-http` (websocket)
- https://nvd.nist.gov/vuln/detail/CVE-2026-56746[CVE-2026-56746] - Improper access control in `netty-codec-http` (CORS)

For the full list, see the https://netty.io/news/2026/07/09/4-1-136-Final.html[Netty 4.1.136.Final release announcement].

== Update

To update to Quarkus 3.27, we recommend updating to the latest version of the Quarkus CLI and run:

[source,bash]
----
quarkus update --stream=3.27
----

Note that `quarkus update` can update your applications from any version of Quarkus (including 2.x) to Quarkus 3.27.
